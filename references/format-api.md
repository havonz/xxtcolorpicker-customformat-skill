# XXTColorPicker 格式模块与回调

适用于包含「重新加载自定格式列表」的桌面版。下述调用依据取色器源码提交 `0d6f60f` 中的 `src/scripts/main.lua`、`colorpicker/init/customformats.lua` 和 `colorpicker/init/callbacks.lua`。本页的行号参数均从 1 开始。需要辨认控件或区分画布、色块和结果行的手势时，见[画布与右侧面板操作指南](picker-interactions.md)。

## 模块与设置

**模块入口。** 启动扫描或手动重新加载时，宿主执行格式文件的顶层代码，传入模块名与路径。返回 `{name = "菜单名", description = "说明", formats = {...}}`。加载器用字符串 `name` 登记格式，`description` 可省略；`formats` 放下述规则。一次重新加载会重新执行顶层代码。把依赖用户点击的操作写在相应回调内。文件报错时查看宿主日志，已有模块可能仍显示上次可用的版本。

**`formats.settingsRule` 是数据表。** `title` 是配置窗口标题。点击「配置」时，宿主结合当前值为 `args` 每行创建一个控件。取色与生成规则执行前，宿主也会遍历 `args` 构造 `set`。没有参数时使用 `settingsRule = {title = "格式设置", args = {}}`。设置按格式显示名及控件名读写，重命名会改变配置查找键。

| 一行声明 | 控件和回调中收到的值 |
| --- | --- |
| `{"紧凑", true}` | 复选框，`set["紧凑"]` 为布尔值。 |
| `{"变量名", "points"}` | 文本输入，返回字符串。 |
| `{"相似度", 85}` | 数值文本输入，生成时读为数值。 |
| `{"相似度", 85, {0, 100, 1}}` | 滑块及数值输入，第三项依次为最小值、最大值、可选步长。宿主滑块采用一位小数精度。 |
| `{"坐标", "绝对", {"绝对", "相对"}, false}` | 字符串下拉列表，第四项为是否允许手动输入，缺省为关闭。 |

## 参数字典

| 参数 | 内容和使用场景 |
| --- | --- |
| `p` | 当前点。读 `p.x, p.y, p.c` 或 `p[1], p[2], p[3]` 得到原图坐标和 24 位 RGB 整数。`p.r, p.g, p.b` 为 0–255 分量。`%06X` 保留六位。底层未定义的寄存器点可能带 `undef=true` 与 -1。 |
| `a, s, x, c` | 逐点格式化时传入四个寄存器的坐标表，只依赖其 `[1]/[2]` 或 `.x/.y`。形参 `c` 是 C 寄存器，要格式化颜色用 `p.c`。 |
| `poslist` | 生成规则及结果行交互用的点集。`ipairs` 依次遍历已定义的 1–9、0、扩展槽。点的 `idx` 是原槽号，`num` 把 0 槽记为 10。数组下标是剔除空槽后的次序。空数组仍可带区域字段。 |
| `poslist.a/.s/.x/.c` | 生成规则中的四个寄存器点。宿主将 A/S 的命名坐标 `.x/.y` 整理为左上/右下；需要整理过的边界时读命名字段。X/C 保留方向。原点可以是有效坐标。 |
| `set` | 当前配置的键值表，键是 `settingsRule.args` 中的控件名称。 |
| `text, row` | 交互所在行的**最后一列**文本以及从 1 开始的行号。不同结果行列数不齐时，Swing 可能为较短行的最后一列补空值；需要交互的多列结果宜使用一致的列数。 |

## 逐点显示和复制

| 回调与作用 | 调用时机与传参 | 返回值、缺省及示例 |
| --- | --- | --- |
| `multiPosFormatRule(p, a, s, x, c, set)` 格式化一个点 | 数字键取色、点列表导入、移动或重取色点，以及重建取色剪贴板时都会调用。一次操作可能对同一点调用多次。 | 返回字符串。槽中显示时去掉首尾空白，复制全部点时直接拼接各次返回值。需要换行就在返回值中加入 `"\n"`。当前备用函数缺少 `return`，自定义模块应显式实现。例如 `return string.format("%d,%d,0x%06X\n", p.x, p.y, p.c)`。 |
| `mouseTrackInfoBottomRule(p)` 显示底部状态栏 | 光标跟踪事件，传当前点这**一个**参数。 | 返回状态栏字符串，例如 `return string.format("X=%d Y=%d", p.x, p.y)`。省略时使用内置坐标及颜色显示。 |
| `mouseTrackInfoZoomRule(p)` 显示右侧面板顶部的光标信息 | 与状态栏同一事件，单独调用，同样只传当前点。 | 返回右侧面板最上方信息行的字符串，例如 `return string.format("#%06X", p.c)`。省略时用内置显示。 |

## 生成与结果行交互

每项 `formats.makeScriptRules[i]` 对应一个结果行。无生成规则时可以使用空数组。宿主调用生成函数时捕获错误并记日志；失败的行可能被跳过，后续按行号查找的交互会随之错位。

| 回调或字段 | 作用与调用时机 | 参数、返回值与示例 |
| --- | --- | --- |
| `makeScriptRules[i] = function(poslist, set) ... end` | 点击「生成代码」时依次执行，快捷键走同一入口。 | 返回字符串生成一列；返回数组生成一行多列。第一条规则直接返回字符串时自动复制；第一条返回数组时保留原剪贴板。例 `return {"点数", tostring(#poslist)}`。 |
| `makeScriptRules[i].maker(poslist, set)` | 需要在同一行声明菜单或双击动作时使用的生成入口。 | 参数、结果形状及首行复制行为与函数简写一致。例 `{maker = function(points) return tostring(#points) end}`。 |
| `rule.doubleClick(text, row, poslist, set)` | 双击结果行时调用，重新读取当前点集与设置。缺省操作为复制最后一列。 | 返回字符串会将该行替换成单元素行数据，原有其他列内容被清空。无返回值可用于仅复制、弹窗等操作。例如 `function(text) copyText(text) end`。 |
| `rule.menu` 或 `rule.menu(text, row, poslist, set)` | 右键打开结果行时收集菜单。静态值是菜单项数组；动态函数每次打开时求值。 | 动态函数返回菜单项数组。例如 `return {{name="复制", action=function(t) copyText(t) end}}`。缺省不提供菜单；动态函数报错或返回非表时宿主放弃此次菜单。 |
| `menuItem.name` 或 `menuItem.name(text, row, poslist, set)` | 构建菜单项时取标签，点击之前执行。 | 接受固定字符串或返回字符串的函数，例如 `function(t) return "复制 "..t end`。无可用标签时宿主显示 `(unnamed)`。 |
| `menuItem.action(text, row, poslist, set)` | 用户点击具体菜单项时执行。文本来自菜单打开时，点集和设置在点击时重新读取。 | 返回值被忽略。复制用 `copyText(text)`，需要写回结果可显式调用 `setMakerResult(row, newText)`。没有函数类型的 `action` 时宿主跳过该项。 |

宿主的默认单元格模型把返回数组内的数值等转换成显示文本。设计格式时显式返回字符串可控制小数、空白和颜色精度。双击及菜单名的错误处理不同：双击或动作抛错会触发错误提示，菜单名回调抛错则保留备用标签。验证器会记录这些错误，即使宿主吞掉异常。

## 源码中出现的其他规则

| 字段 | 当前版本的状态 |
| --- | --- |
| `singlePosFormatRule` | 内置样例写作 `function(p, a, s, x, c, set) → string`。有取规则的方法，当前内置取色和剪贴板路径均调用 `multiPosFormatRule`，没有找到对它的实际调用。 |
| `testRules` | 可读取的表，默认空表。当前内置流程没有调用点，因此没有可验证的回调时机或参数、返回值约定。 |
| `rightClickRules` | 可读取的表，默认空表。结果行右键实际读取 `makeScriptRules[row].menu`。 |

完整的配置、双击、动态菜单、菜单名称与动作示例见[相对点阵脚本](../examples/relative-points.lua)，对应输入及逐项期望值见[样例 JSON](../examples/relative-points.json)。
