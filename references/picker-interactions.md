# 画布与右侧面板操作指南

同一个「右键」有三种常见含义：在画布上撤销色点，在「自定格式」标签上管理格式文件，在生成结果行上打开该行的菜单。写格式前先确定用户点的是哪一处。

桌面版的取色工作区中，画布在左，取色面板在右。下面以简体中文界面、11 个已取色点和一个返回两列结果的格式为例。槽位的位置固定，结果表的行数和列数由所选格式决定。

## 右侧面板，从上往下看

右栏最上面是一行随光标变化的文字。下面依次是格式选择、采样点、生成结果和区域坐标。按界面顺序读下来：

```text
当前像素信息    (16, 26):0x176b87:(23,107,135)
自定格式        [格式名称 ▾]                    [配置]

[清 1]   [37, 42, 0x176B87]   [蓝绿色块]   [①]
[清 2]   [99, 42, 0x008D90]   [青绿色块]   [②]
  …            固定槽依次排到 9，再到 0
[清 0]   [37, 201, 0x536CB3]  [蓝色色块]   [〇]

[删]     [99, 201, 0x557F9C]  [蓝灰色块]    11    ← 扩展点表
[全清(Z)]             [生成代码(F)]            [标记]

首点坐标        37, 42                           ← 生成结果表，第 1 行
色点总数        11                               ← 生成结果表，第 2 行

[A]  10   15      [S]  127  118                  ← 每个字母后依次是 x、y
[X]  69  126      [C]  190  228
```

以第 1 槽为例：单击蓝绿色块复制 `0x176b87`，双击同一色块复制 `37, 42`，双击色块左侧的文本框复制 `37, 42, 0x176B87`。下方生成结果的「首点坐标」属于另一张表，双击它走结果行回调。

| 点哪里 | 操作与效果 | 写格式时用什么 |
| --- | --- | --- |
| 最上方的只读信息行 | 鼠标在图片上移动时，显示当前像素的信息。画布下方的状态栏也可同时显示另一段文字。 | 右栏顶部用 `mouseTrackInfoZoomRule(p)`，画布下方用 `mouseTrackInfoBottomRule(p)`。画布浮镜里的像素和网格由宿主绘制。 |
| 「自定格式」四个字、旁边的下拉框、「配置」按钮 | 右键点**标签文字**可「从资源管理器查看」当前格式或「重新加载自定格式列表」。下拉框选择格式。「配置」打开当前格式的选项。 | 标签的菜单由宿主提供。用 `name` 决定下拉框名称，用 `settingsRule.title/args` 定义配置；在后续回调的 `set` 中读值。修改或切换格式后可按 F 用新规则重新生成。 |
| 固定槽 1–9、0 | 从左到右是「清 N」、只读点色文本、色块、编号开关。清除按钮只清该槽。文本框获得焦点后按空格，可把指针移回该点。 | `multiPosFormatRule` 决定点色文本。色块复制的十六进制颜色或坐标使用内置格式。固定槽的文本和色块监听器按点击次数处理，右键也没有结果行菜单。 |
| 第 0 槽下方的扩展点表 | 固定槽满后继续取色，会出现 11、12… 行。每行依次是「删」、文本、色块、编号。左键双击文本复制该行文本，单击色块复制颜色，双击色块复制坐标。选中行按空格可定位；点「删」移除该点，后续编号前移。 | 与固定槽共用 `multiPosFormatRule`。这里显示的是输入的采样点，每行的末列是编号。 |
| 「全清(Z)」「生成代码(F)」「标记」 | 全清会清空固定槽和扩展点。A/S、X/C 和已生成的结果仍保留，再按 F 才会用当前点集刷新结果表。「标记」开关控制画布上的编号，固定槽还受本行编号开关控制。 | F 执行 `makeScriptRules`。隐藏标记只影响显示，已取的点仍会传给 `maker`。 |
| 按钮下方的生成结果表 | 左键单击选中行。左键双击默认复制该行**最后一列**，即使点的是第一列。右键先选中该行，再按该行规则打开菜单；macOS 此处也支持 Control + 左键。 | `makeScriptRules[i]` 对应第 i 行。自定义双击用 `rule.doubleClick`，右键用 `rule.menu` 和菜单项 `action`。只有声明菜单的行才提供这些选项。 |
| 最下方两行 A/S、X/C | 每个字母按钮右边各有 x、y 两个数字框。点字母复制该端点的坐标对；双击数字框中的数字只复制该数值。编辑数字可调整端点。 | 逐点规则读 `a, s, x, c`，生成和菜单规则读 `poslist.a/.s/.x/.c`。A/S 常用作裁图区域，X/C 常用作找色或 OCR 的搜索范围。 |

## 在画布上取点与选区

打开图片后，打开「标记」可在已启用的色点位置看到圆形编号。编号 1–9、0、11… 与右栏槽位对应。框选 A/S 后，矩形的四角和四边中点带红色方形手柄；X/C 的手柄是黄边黑色。放大镜开启时通常浮在画布右上角，指针靠近时会让到左侧。光标处的细框与浮镜中心指向同一个原图像素。

取点和区域使用**原图像素坐标**。缩放改变显示大小，脚本仍收到相同的原图坐标。下表的快捷键在图片获得焦点时使用，用户的自定义键位可覆盖默认设置。

| 画布操作 | 宿主行为 |
| --- | --- |
| 左键短按图片或按 Enter | 先填第一个空的固定槽，顺序为 1–9、0；固定槽已满时追加扩展点。按数字键则直接写入指定槽，包括覆盖旧点。画布双击没有专用格式回调，连续短按可以连续取点。 |
| 右键单击图片或画布留白 | 撤销离点击位置最近的一个已取色点，按原图像素距离计算。重合或等距时删列表中靠后的点。 |
| 左键拖动、滚轮 | 普通左拖平移画布，滚轮围绕指针缩放；从可见矩形的手柄开始拖动时优先调整矩形。 |
| Shift + 左拖；Ctrl 或 Alt + 左拖 | 前者框选 A/S，后者框选 X/C。按住相同修饰键，在同一像素按下并释放左键，可以清除相应选区。 |
| 拖已画好的矩形 | 普通左拖 A/S 边或角的手柄可调整大小；按 Ctrl 或 Alt 左拖手柄可调整 X/C。右拖可整体平移 A/S，Ctrl 或 Alt + 右拖可整体平移 X/C。 |
| A、S、X、C；Shift + 对应字母 | 单按字母把光标位置写入相应端点。加 Shift 把指针移到该端点。D 复制 A/S 四个坐标，Shift + D 复制 X/C 四个坐标，E 交换两组端点。 |
| Shift + 数字、Z | 前者清指定槽，后者清所有采样点。 |
| R、Shift + R、M | R 保留坐标，在当前图片上重新采样颜色。Shift + R 从剪贴板导入宿主可识别的点表，例如 `{{37,42,0x176B87}}`。1 号槽已有点时，M 以该点为基准将整组平移到光标位置并重新取色。 |
| W、F | W 用 `multiPosFormatRule` 重新拼接各点文本并复制。F 用 `makeScriptRules` 刷新结果表，第一条规则直接返回字符串时也会复制该字符串。 |

## 把需求落到正确的回调

- **「双击色点复制 JSON」**：如果用户指取色槽的文本框，让 `multiPosFormatRule` 返回该点的 JSON，宿主双击时会复制它。若还要保留原有槽文本，可以在生成结果表增加一行专门复制 JSON。色块另有固定的颜色和坐标复制行为。
- **「右键按框选范围预览二值图」**：可以让用户在画布上用 Shift 框选 A/S，再在「生成代码」下面的结果行点右键。将动作放在那一行的 `menu` 中，读 `poslist.a/.s`，按两端坐标取图。若用户明确要求在画布上直接弹出菜单，这属于宿主画布交互，格式文件没有对应的画布菜单入口。
- **「移动鼠标时显示颜色，点生成时输出多点找色」**：顶部或状态栏的悬停规则只收当前点 `p`；生成规则收完整 `poslist` 和 `set`。两处可以各用一种输出格式。

各回调的参数、返回值及多列结果行为见[格式回调手册](format-api.md)。点色与区域手势核对自 `XXTColorPickerMainWnd`、`_1FCPScrollImagePanel` 以及宿主内置的 `main.lua`、`colorpicker/init/callbacks.lua` 和默认键位表。
